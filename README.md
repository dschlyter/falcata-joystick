# Falcate Joystick

ASUS ROG Falcata analog key reader / joystick

This keyboard has analog keys, but no official way to actually use it as analog input

## Web test

Open the [standalone web page](hid-keyboard.html) to try it out.

Note this is effectively a **key logger**, which will log keys from your keyboard on other sites after you connect. Close the tab before you do anything sensitive.

## Python

Python script using [vgamepad](https://github.com/yannbouteiller/vgamepad) to simulate an actual gamepad from your keyboard.
